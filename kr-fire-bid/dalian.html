韩国系列 · 消防改造招标情报与竞标方案

在中国境内、与韩资企业及中韩合作园区相关的消防系统改造（消防改造 / 消防设施提升 / 消防专项改造）项目的公开情报梳理，以及由此推导出的可执行竞标方案。

先说结论：韩资工厂（三星、LG、SK、现代、韩泰等）在中国的消防改造，基本不出现在公开招标平台——它们走自有 SRM／邀标。公开平台上真实可投的，是「韩资工业园 / 中韩产业园」配套工程、政府与国企的院校医院厂房改造。因此竞标方案必须分成两条腿：公开标（现在就能投）+ 韩资 SRM 注册（3~5 个月后才有标的）。

  • 韩资渠道是封闭的。三星（nbuy / 各法人 SRM）、LG 电子与 LG Display（合作法人采购门户）、SK 海力士（无锡/大连 SRM）、现代汽车与摩比斯、韩泰轮胎等，消防改造以「询价 + 邀标」形式在同一批已注册供应商中循环，公告不外发。想进入这条线，动作是供应商注册与 EHS 预审，不是等公告。
  • 中韩合作园区是公开可投的桥。中韩（惠州）产业园、盐城韩资工业园、潍坊北海中韩产业园、烟台中韩产业园的配套基建在公共资源交易平台公开招标，消防（消防水、报警、排烟、验收配合）常作为分包出现在总承包包里。
  • 公开标集中在院校、医院、厂房三类。院校（校园消防专项改造）预算透明、评分偏综合评估法；医院与厂房更看「不停业施工」的组织能力，这正是韩资项目最看重的同一能力——可作为业绩铺垫。
  • 资质门槛分水岭：院校/医院类多要求「消防设施工程专业承包二级及以上」；厂房整体改造（如圣威厂房）要求「建筑工程施工总承包二级及以上 + 安全生产许可证」，并卡 3 年内 500 万以上类似业绩。

04竞标方案（可直接执行）

4.1 选标：先算「值得投」再算「怎么投」

把每个候选标按 100 分打分，低于 65 分不投——消防改造标书成本约 0.8~1.5 万元/标（含保证金资金占用、电子标工具、现场踏勘、方案编制），投错标的隐性亏损比不投大。

维度权重满分判据本项目自评要点
资格匹配25资质、业绩、人员全部满足且有冗余总承包二级+500万业绩=硬门槛，缺一项即 0 分
技术可交付20有同类厂房/医院不停业施工案例工厂/医院经验＝韩资项目的通行证
价格空间20控制价与市场成本差 ≥8%用已结标项目的「中标价/控制价」比率校准
竞争格局15本地投标人 ≤6 家且无垄断性对手三次流标、二次公告多为「条件过苛」信号
资金与结算10自筹/债券已到位，进度款 ≥70%院校类自筹项目要核实财政支付节奏
战略价值10能作为韩资 SRM 的业绩背书厂房/外资标准项目加分

4.2 资格与文件清单（提交前逐项打勾）

  • 营业执照（经营范围含消防设施工程 / 建筑工程施工）
  • 消防设施工程专业承包资质（二级起；厂房整体改造需建筑总承包二级+）
  • 安全生产许可证（有效期覆盖投标日与工期）
  • 注册建造师（机电或建筑专业）+ 安全 B 证 + 近 3 个月社保在本单位
  • 类似业绩 1~3 个（合同 + 中标通知 + 竣工验收/消防验收备案，缺一件常被判无效）
  • 近 3 年审计报告 / 纳税与社保证明 / 无重大违法记录声明
  • 信用中国、住建领域信用平台查询截图（投标前 7 日内）
  • 投标保证金（常见控制价 2%）或电子保函；履约保函（常见 10%）预案
  • 电子标工具（各省专用，如陕西 .sxz）、CA 锁、加密上传演练
  • 联合体协议（本项目不接受联合体时，需以分包锁定消防专业力量）

4.3 技术标：把「不停产/不停诊」做成主线

消防改造的评分离不开三件事，而它们在韩资语境里权重更高：不中断既有系统、隐蔽工程可验证、验收一次通过。

  • 分区与分期矩阵：把建筑切成 3~6 个施工单元，每单元「停系统时长、临时替代方案、恢复验证」三列表格化。厂房类按产线、医院类按楼层病区。
  • 临时消防不空窗：拆改期间临时消火栓/临时报警（无线联动或临时主机）＋ 24h 值守记录，写进方案并附示意图。
  • 隐蔽工程留证：管道压力试验、线缆绝缘、防火封堵三类的影像+数据双记录，按点位编号归档（验收阶段最容易被卡）。
  • 验收路径前置：开工前与属地消防审验/住建部门确认「备案 or 验收」路径、资料清单、时间窗，把验收排期写进总进度。
  • 韩资附加项（针对 SRM 邀标）：中韩双语方案与作业许可（PTW）模板、EHS 交底记录、进场人员体检与安全教育、动火/高处/受限空间作业票流程——这些在韩资工厂是「没有就不让进场」，在公开标里则是差异化加分。
