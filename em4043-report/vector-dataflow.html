关键概念速查
Collection 命名规则 每个知识库 kb_id 对应 Qdrant collection kb_{kb_id}。开启增强后逻辑 ID 为 {kb_id}_enrichment，实际 collection 为 kb_{kb_id}_enrichment，共享同一 Embedding 模型与维度。
向量 ≠ 唯一存储 Qdrant 存向量+payload；MySQL 存切片元数据与状态；BM25 存倒排索引。三者通过 slice_id 关联，删除 KB 需同步清理全部三层。
PageIndex 独立 PDF 章节目录树存 pageindex_trees/ + MySQL，走 LLM 树搜索，不写入 Qdrant 主 pipeline，与向量检索并行独立。
写入并发控制 QDRANT_MAX_CONCURRENT_WRITES 全局 Semaphore 限制跨任务并发 upsert；单任务内 batch 串行，避免 httpx 客户端竞态。
检索入口统一 管理后台 / 第三方 API 均经 smart_search() 路由：无增强 → HybridRetriever；有增强 → MultiVectorRetriever 双 Collection 融合。
