mods 是什么？

mod 是 Claude Code 2.1.287 起可用的官方功能。插件（plugin）内的 JavaScript/TypeScript 代码直接接收工具调用、提示词提交等事件，从而改变 Claude Code 的行为或绘制界面。本文整理 mod 究竟是什么、能做什么、在哪里运行、与类似的其他功能有何不同，以及如何开启和关闭。

一句话定义

mod 在 Claude Code 内直接运行的插件（plugin）代码。每当 Claude Code 要做某件事——如工具调用、提交提示词、绘制界面——“事件（event ）“发生时，mod 是用 JavaScript 或 TypeScript 写的函数（钩子、 hook）接收该事件，进行观察、修改，或直接拦截后代为处理。

一句话自述：mod 是插入 Claude Code 事件之间的中间件（middleware）。观察、修改、代为回答。

Claude Code 把通过配置文件注册的原有方式也称为“钩子”，但在 k-mods 文档中，“钩子”始终指 mod 的处理程序。以 shell 命令、HTTP 请求、提示词运作的原有方式称为“配置钩子（settings hook）”这样单独称呼。

官方文档： Mods overview

如何运作

单个 mod 的代码（钩子模块、 hooks module ）是 register(on) 导出函数，并在其中 on(이벤트 이름, 핸들러)注册事件。Claude Code 会向处理程序传入三样东西。

  • $：是 mod API。是与外部世界接触（绘制界面、读取文件等）的唯一通道。
  • e：是事件数据。只读，无法修改。
  • next：调用下一个处理程序（其他 mod 或 Claude Code 自身行为）的函数。

处理程序以这三者之一来处理事件。

处理方式 作用 代码
观察（observe) 原样放行 return next(e)
变形（rewrite) 修改内容后放行 return next({ ...e, text: e.text.trim() })
响应（answer) next不调用，直接回答以中断链条 return { deny: '이유' }

例如，每次工具调用就把计数加一、显示在加载动画旁边的 mod 长这样。

let calls = 0

export function register(on) {
  on('tool.call', async ($, e, next) => {
    calls += 1
    $.ui.invalidate('ui.render') // 화면을 다시 그려 달라고 요청
    return next(e) // 도구는 평소대로 실행
  })

  on('ui.render', { component: 'Spinner' }, async ($, e, next) => {
    return next({ ...e, props: { ...e.props, suffix: ' · 도구 ' + calls + '번' } })
  })
}

第一个钩子 tool.call 只做观察，第二个钩子则 ui.render 改写，在加载动画文案后面附上调用次数。若同一事件上挂了多个 mod，会像中间件链一样按顺序执行。注册顺序规则与失败处理见 速查表 和 做一个自己的 mod中有更多说明。

mod 能做的事

配置钩子、技能、状态栏（status line ），MCP 服务器则都是 Claude Code 外部 中运作。只是执行脚本，或把文字、工具交给 Claude。mod 是 Claude Code 不中运行，所以才能做这些事。

  1. 绘制界面：转录旁边的面板（pane）或输入框上方的条（AbovePrompt）绘制标签页、按钮、输入框。
  2. 重绘 Claude Code 自身界面：修改或重新绘制工具调用行、加载动画、Claude 提问时使用的对话框等。
  3. 拦截工具调用与请求：暂停工具调用并询问用户，或不经执行直接回答，或把某个请求发给其他模型。
  4. 用命令直接运行我的代码 ：不经 Claude 回合、立即执行的 /명령어。可以让它在 Claude 正在工作时也执行。
  5. 钩子间共享数据：同一 mod 内的钩子共享同一文件的变量。例如一个钩子统计工具调用次数，另一个钩子把该值显示在界面上。

官方文档： What a mod can do

在哪里运行

mod 的钩子在插件被加载的所有会话中都会运行。不过 绘制界面的功能只在终端和桌面应用中显示。

运行环境 钩子执行 界面显示
终端（claude）、编辑器集成终端、JetBrains 插件 已 显示
桌面应用 Code 标签页（不含 WSL 会话） 已 可见（部分终端专用元素除外）
桌面应用的 WSL 会话 不支持（在 WSL 中插件本身就不支持） 不可见
VS Code 扩展聊天面板 已 不可见
claude -p, Agent SDK 已 不可见
claude.ai 与移动应用的远程控制（Remote Control) 支持（在我的电脑会话中） 仅在我的电脑终端中可见
云端会话 仅当插件能触达云端会话时支持 不可见

绘制界面的 mod 最好先确认当前在哪个应用中运行，在无法绘图的环境里改用转录行或命令回答文本代替。

官方文档： Where mods run

与配置钩子、技能、MCP 有何不同

mod 配置钩子（settings hook) 技能（skill) MCP 服务器
本质 在 Claude Code 进程内直接运行的插件函数 在生命周期事件上由 Claude Code 执行的 shell 命令、HTTP 请求、提示词 包含 Claude 所读指南的 SKILL.md 外部进程或服务向 Claude 提供工具
可修改的内容 工具调用、提示词、命令、回合、界面上绘制的内容 事件是否继续、工具调用的参数与结果、添加到 Claude 的上下文 Claude 知道什么、做什么 Claude 可使用的工具
是否绘制界面 可以 无法 无法 无法
用什么制作 JavaScript 与 TypeScript 脚本 + settings.json 条目 Markdown 用任何语言编写的服务器
何时选用 需要面板或输入框上方的条、需要自定义命令、需要改变事件本身时 只需用已有脚本拦截、允许或记录事件时 一直在粘贴同样的指南时 当 Claude 需要接触外部系统时

一个插件可以同时包含 mod、技能、MCP 服务器。k-mods 的 mod-store这样把命令（/k-mods）与界面绘制兼具的 mod 就是例子。

官方文档： Compare mods, settings hooks, skills, and MCP servers

Claude Code 内置的 mods

Claude Code 自身的部分功能也是用 mod 实现的。 /plugin → Installed 标签页的 Built-in 中查看，不能更新或删除，但可以关闭。

/plugin中显示的名称 作用 关闭方法
cc-plugin-agents-md AGENTS.md作为项目指南加载 /plugin中关闭，或修改使用哪个指南文件的设置
cc-plugin-diff /diff 负责命令及其面板 /plugin 中关闭后 /diff以 Claude Code 基础版本运行
cc-plugin-plugin-authoring 使用 mod 所需的 plugin-authoring 提供技能 /plugin中关闭
cc-plugin-sec-default 保护组织管理的设置不受用户安装的 mod 影响 用户无法关闭。管理员在 managed settings 中确定顺序
cc-plugin-telemetry Claude Code 与内置 mods 的用量记录上报 /plugin中关闭，或关闭分析功能本身（DISABLE_TELEMETRY 等）
cc-plugin-you-should-know 在任务变长时提醒容易遗漏事项的辅助代理 默认关闭。 /plugin中开启和关闭

diff, agents-md, sec-default, telemetry 的来源是 claude-code 仓库的 mods 目录中连测试一起公开。适合参考真实 mod 代码长什么样。

官方文档： Mods built into Claude Code

开启和关闭 mods

关闭范围不同，方法也不同。

  • 仅单个 mod: /plugin → Installed 标签页中禁用或删除。
  • 本次会话的所有 mod: claude --safe-mode开始。其他定制也会一并关闭。
  • 我安装的所有 mod、所有会话: ~/.claude/settings.json 在 "disableAllHooks": true。配置钩子和自定义状态栏也会一并关闭，只有组织管理的内容继续运行。

若是组织成员，管理员还可以通过 managed settings 进一步限制 mod 的加载本身。详细内容见 安全指南里。

早期访问时 CLAUDE_CODE_ENABLE_FUNCTION_HOOKS 的话请删除。Claude Code 2.1.287 起会忽略该变量，因此 0，mod 也不会关闭。

官方文档： Turn mods on or off

版本要求

  • 终端 ：Claude Code 2.1.287 及以上。 claude --version来确认。
  • 桌面应用 ：2.1.286 及以上。在 Code 标签页中 /status 输入后会 Claude Code 行会显示版本。

版本过低时，mod 虽能安装但不会被加载。安装与更新的方法见 安装指南。
