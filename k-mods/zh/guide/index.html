指南

从 mods 是什么，到安装、安全使用、亲手制作，都整理好了。

  • mods 是什么？mod 是 Claude Code 2.1.287 起可用的官方功能。插件（plugin）内的 JavaScript、TypeScript 代码可以直接接收工具调用、提交提示词等事件，从而改变 Claude Code 的行为或绘制界面。阅读
  • 安装指南k-mods 是一个普通的 Claude Code 插件市场。所以安装、更新、卸载全都通过 Claude Code 的 /plugin 命令和 claude plugin shell 命令完成。阅读
  • 如何安全使用 modmod 没有沙箱，会以我的权限在 Claude Code 里运行。所以安装前了解它能做什么很重要。阅读
  • mods 速查表（韩语）把开发 mods 需要的文件结构、事件、API、渲染位置和限制压缩成了表格。说明已尽量精简，完整背景请先看“mods 是什么？”和“做一个自己的 mod”。阅读
  • 做一个自己的 mod制作 mod 有两种方式：用自然语言让 Claude 来做，或者自己写代码。本文两种方式都讲，最后再接到把做好的 mod 发布到 k-mods 的流程。阅读
