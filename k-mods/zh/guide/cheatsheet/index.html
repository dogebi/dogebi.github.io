mods 速查表（韩语）

把开发 mods 需要的文件结构、事件、API、渲染位置和限制压缩成了表格。说明已尽量精简，完整背景请 mods 是什么？ 和 做一个自己的 mod请先看。

基准版本为 Claude Code 2.1.291 。每个版本的事件与 API 都可能变化，准确的定义请见 --plugin-dir加载 mod 时生成的类型声明（.claude-plugin/types/claude-code/index.d.ts）优先于本文档。

文件构成

文件 必填 内容
.claude-plugin/plugin.json 是 插件清单。作为 mod 不需要额外字段
hooks/hooks.json 是 modules ：钩子模块路径数组。 "modules": ["./register.js"] 那样只写一个。配置钩子也 hooks 可以在该键下一起存放
钩子模块（例如： hooks/register.ts) 是 mod 的入口。 register(on, options) 导出为 ES 模块。扩展名： .js, .mjs, .cjs, .jsx, .ts, .mts, .cts, .tsx
types/index.d.ts （清单的 types所指） $.state时，或只在给 mods API 添加命名空间时 PluginState 声明值与额外命名空间
*.test.ts / *.test.tsx 否 claude plugin test所运行的测试

registeron 和 options 接收。 optionsuserConfig 字段的值，且已填入默认值。

钩子函数参数

on(이벤트 이름, 매처?, 훅) 来注册。matcher 是筛选事件字段的可选过滤器， on 的返回值是 .catch(핸들러)可以附加的 registration。

参数 含义
$ mods API。必须 $.네임스페이스.메서드(...)要写全路径
e 事件输入值。它被深度冻结（frozen），无法直接修改。要改动就复制后 next交给
next(e) 调用下一个处理器（其他 mod，最后是 Claude Code 自身的行为），并以结果 resolve
next.signal 事件中断时会 abort 的 AbortSignal
next.origin 保存触发该事件来源的 { plugin, tier } 。Claude Code 自身则 { plugin: 'engine', tier: 'core' } ，而 mod 的 tierprepend/user/append/builtin
next.budget 此钩子的超时时间。 next.budget.ms 为总上限， next.budget.remainingMs为剩余时间
next.to(e, tier) append/builtin/core 中，会跳到更靠后的 tier。 prependPlugins·appendPlugins中所属的 mod 才能被调用
next.error, next.called .catch 只能在处理函数内使用。 next.error.kindthrow 或 timeout, next.called 是失败的钩子 next是否调用过

事件

在表格的“可以返回的内容”中 next(e) 原样放行， next({ ...e, text }) 只改那个字段后放行，直接返回对象则 next而不调用它、直接给出回答。

工具

事件 何时 可以返回的内容
tool.call 工具执行之前 next(e), { deny: 이유 }, { result }
tool.check tool.call 和 PreToolUse 钩子之后、决定是否执行时 { decision } (allow/ask/deny)
tool.describe 首次把工具说明发给 Claude 时，每个工具一次 { description, isDeferred? }

提示与 Claude 读取的内容

事件 何时 可以返回的内容
prompt.submit 提示被提交时 next({ ...e, text }), next({ ...e, context }), { drop: 이유 }
prompt.fill, prompt.suggest 草稿或灰色建议即将填入提示输入框时 用修改后的文本 next(e)
prompt.edit 用户编辑提示词输入框时 next(e)
prompt.compose 绘制系统提示词时 { sections }
prompt.section 系统提示词的每个命名区段一次 { text } ，若要省略 { text: null }
prompt.context 每个对话一次，首条消息和发送的上下文 { blocks }
prompt.attachment Claude Code 自行添加提醒这类消息时 { text } ，若要省略 { text: null }
skill.prompt 技能文本向 Claude 展开时 { text }
attribution.text 生成提交与 PR 归属文案时 { text }

命令与设置

事件 何时 可以返回的内容
command.run 命令执行之前 { text }, {}, next(e)
command.describe 用于命令列表的说明，每个命令一次 { description, argumentHint, isHidden }
config.set /config 行值即将改变时 next({ ...e, value }), { deny: 이유 }
config.describe /config 每行一次 { label, description, isHidden }

轮次

事件 何时 可以返回的内容
turn.start 回合开始时 next(e)
turn.step 向模型发送单个请求之前（有工具调用时会多次） yield* next(e), next({ ...e, model }), next({ ...e, effort })
turn.complete 回合结束时 next(e) ，或在回答下方显示一行的 { text }

会话

事件 何时 可以返回的内容
session.start 每个 mod 一次，在首条提示词之前（重新加载后也会执行， /clear·/resume·/branch 之后就不行了） next(e)
session.end 会话结束，或 /clear·/resume·/branch next(e)
session.compact 压缩对话之前 { skip: 이유 }
session.receive, session.send 与其他智能体、会话收发消息时 获取 { consumed: 이유 } 、发送 { isDelivered: false, reason }
session.append 对话中每条留存的消息保存之前 next({ ...e, message })
session.attach, session.detach 其他应用连接或断开会话时 next(e)
session.measure 每个回合结束时，套餐额度百分比变化时 next(e)

子智能体

事件 何时 可以返回的内容
agent.offer 向 Claude 建议子智能体类型时 要隐藏 { isOffered: false }
agent.spawn 子智能体或智能体团队同伴启动之前 指定模型 next({ ...e, model }) 、拒绝 { deny: 이유 }

接口

事件 何时
ui.render 绘制渲染位置之前
ui.resolve mod 加载时，每个应用、站点、mod 各一次
ui.press, ui.input, ui.select mod 绘制的 Button/Input/Select使用时
ui.focus, ui.scroll 焦点或滚动位置即将改变时
ui.close 面板即将关闭时
ui.message Client 元素向 mod 发送数据时
ui.fault mod 绘制的 Client加载、绘制、执行失败时（2.1.289+）

其他 mod

事件 何时 可以返回的内容
plugin.register 钩子模块即将加载时。 e.uses里包含该 mod 接收的事件、调用、环境变量和状态 { refuse: 이유 }
engine.create 在创建这个 mod 专用的 mods API 时 增删命名空间后的 API

遥测

事件 何时 可以返回的内容
telemetry.log, telemetry.mark 留下用量记录或显示功能使用时。已安装的 mod 则 { to: 'collector' } matcher 必填 next(e), { deny: 이유 }

设置钩子事件: classic.<이벤트> 的形式（例如： classic.Stop, classic.PostToolUse). e与设置钩子从 stdin 收到的 JSON 完全一致。

mods API 调用本身 ：所有 mods API 方法都是 네임스페이스.메서드 同名事件（例如： fs.read, model.complete, ui.open ）。前面的 mod 拦截后 next(e), { deny: 이유 }, { value }即可回答。

$ API 命名空间

命名空间 方法 含义
$.plugin name, root 此插件的名称和目录
$.ui resolve, invalidate, open, close, panes, focus, scroll, toast, status, log, notice, ask, copy, selection, blit 绘制界面、开关面板、显示提示条与问题
$.command register, run, list /명령어 添加、执行、列表
$.tool register, call, check, list Claude 可用工具的添加、调用、检查、列表
$.agent register, spawn, list 子智能体的注册、执行、列表
$.model complete, fork, classify 在对话之外直接向模型提问
$.prompt submit, read, fill, suggest, compose 提交、读取提示，填充输入框
$.turn abort 中止进行中的回合
$.session messages, cwd, root, model, turns, id, repo, surfaces, usage, version, compact, send, append, authorize 读取会话信息，向其他会话发送消息
$.config list, set /config 读取、写入值
$.settings read 读取设置文件与管理策略
$.env get, set 读取、写入环境变量
$.fs read, write, list, exists, stat, ancestors 读取、写入、列出文件
$.store get, set, delete, keys 本机所有会话共享的键值存储
$.state get, set (+ atom, read, update, derive, memberOf 导入) 响应式状态。写入值后，读取该值的界面会自动重绘
$.clock now, sleep, after, every 定时器（setTimeout·setInterval 代替）
$.http fetch 网络请求
$.process run, spawn 运行程序
$.mcp call, connect 调用已连接的 MCP 服务器工具
$.audio play, speak 播放声音
$.telemetry log, mark 用量记录（只有 Claude Code 或内置 mod 调用时才实际发送）

限制 (limits)

条目 值
单个钩子的执行时间（next·不含 mods API 调用等待时间） 10 秒， prompt.edit为 50ms
.catch 处理函数执行时间 1 秒
session.end 整个钩子 按 SessionEnd 钩子的预算（默认 1.5 秒）
$.process.run 超时 默认 30 秒，最大 10 分钟
$.model.complete 的 maxTokens 默认 1024，最大 64,000 或模型上限
$.fs.read/$.fs.write 每个文件 4MiB
Text 单个子字符串 10,000 字
$.store 整个 4MiB JSON
$.session.messages() 最近 4,096 条记录
$.ui.invalidate('ui.render') 重绘 限制为每秒 10 次（终端中可见的面板、展开的条、提示行是 30 次）。更快的调用会被合并
$.ui.toast 默认显示 4 秒
未经用户请求打开的面板 终端宽度 144 列起显示，打开过一次则从 110 列起显示
命令、工具、子智能体、面板名称 英文字母、数字、_·-，最多 64 字
claude plugin test 一个测试 默认 5 秒

设置、环境变量

名称 在哪里 含义
CLAUDE_CODE_PLUGIN_DIRS 环境变量或 ~/.claude/settings.json 的 env --plugin-dir那样加载插件目录
CLAUDE_CODE_PLUGIN_DIR_WATCH 环境变量 1 时，非交互式会话在保存时也会 --plugin-dir 重新加载 mod
prependPlugins, appendPlugins managed settings（没有 managed settings 的个人用户可自行设置） 把 mod 的执行顺序固定在用户 mod 之前或之后
allowManagedModsOnly managed settings（内置防护选项） 仅加载组织 mod 和内置 mod
allowModsToOverrideDenyRules managed settings（内置防护选项） 用户 mod deny 反转规则以允许批准
allowManagedHooksOnly managed settings 拦截非组织的钩子与安装类 mod
disableAllHooks 所有设置文件 关闭已安装 mod 的全部钩子（在个人设置里只关自己的 mod，在 managed settings 里则全关）
disableSideloadFlags managed settings 启动时 --plugin-dir·--plugin-url 拒绝
pluginConfigs 用户或 managed settings mod 的 userConfig 保存值

命令

命令 作用
/plugin 标签页下方 N mods active · 이름那样显示已加载的 mod 数量
claude plugin validate <경로> 读取清单和钩子模块，把错误、接收的事件（hooks:），调用的 API（calls: ）并输出。 --strict 会把警告也当成错误， --json会作为机器可读的报告
claude plugin test [경로] .test.ts/.test.tsx结尾的文件全部执行。失败则退出码为 1
claude --plugin-dir <경로> 只在一个会话里加载插件目录，每次保存都重新加载钩子模块。可重复多次
/reload-plugins 把插件改动立即应用到当前运行的会话
