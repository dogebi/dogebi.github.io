secret-vault

secret-vault · by Ray Amjad

把用户粘贴或工具读取到的 API 密钥、邮箱、IP 地址在发给模型前替换成占位符。工具执行前再还原成原值。

❯ /plugin marketplace add dogebi/k-mods
❯ /plugin install secret-vault@k-mods
$ claude plugin marketplace add dogebi/k-mods
$ claude plugin install secret-vault@k-mods

对已打开的会话，用 /reload-plugins 即可立即生效。需要 Claude Code 2.1.287 及以上。

注意事项

  • k-mods 中已经收录了来自 davila7/claude-code-templates 的「secret-redactor」(只遮蔽工具结果、阻止复用的方式)。这个 mod(原名也是 secret-redactor，因重名而注册为 secret-vault)与它不同，通过 prompt.submit 钩子连用户直接粘贴的值也一并遮蔽，并在工具执行前把遮蔽的值还原，从而不打断工作流。两个 mod 有重叠的领域，建议市场/运营方面研究一下是否合并。
  • README 中写着「需要 CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1」(看起来是早期 early-access 时期的表述)，但在 2.1.291 中不做任何额外设置 validate 就直接通过了。
