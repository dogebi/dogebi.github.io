ko-ui

ko-ui · by moduvoice

把斜杠命令说明、/config 条目、状态栏这类界面文案按翻译词典显示为韩语。

❯ /plugin marketplace add SeongGwangJu/k-mods
❯ /plugin install ko-ui@k-mods
$ claude plugin marketplace add SeongGwangJu/k-mods
$ claude plugin install ko-ui@k-mods

对已打开的会话，用 /reload-plugins 即可立即生效。需要 Claude Code 2.1.287 及以上。

注意事项

  • 需要 Claude Code 2.1.287 及以上。在 2.1.285 中 CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 需要开启环境变量才会加载。
  • 采用完全没有模型调用和网络请求的固定词典(dict.json)替换方式，因此不消耗 token。
  • Spinner 单词的翻译仅在 terminal 画面生效(desktop 保持原文，其余翻译在 desktop 也会生效)。
  • 未被翻译的新文案 /ko-dump 来确认 dict.json中直接添加(最多记录 200 条)。
  • 权限确认窗口、欢迎画面、选项值、错误消息、提示下方的胶囊文字，因为没有钩子、或者翻译后会丢失其他信息，所以保持原文。
