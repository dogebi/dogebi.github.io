agent-compact-advisor

agent-compact-advisor · by apolenkov

在状态栏用 0~100 分显示现在是否适合 /compact。每次压缩都会自动附加包含目标、决定和剩余事项的保留模板。

❯ /plugin marketplace add dogebi/k-mods
❯ /plugin install agent-compact-advisor@k-mods
$ claude plugin marketplace add dogebi/k-mods
$ claude plugin install agent-compact-advisor@k-mods

对已打开的会话，用 /reload-plugins 即可立即生效。需要 Claude Code 2.1.287 及以上。

注意事项

  • P1（目标达成概率，分数权重 20）需要本地 127.0.0.1:8010 上运行着名为“Kev 的 System One”的独立服务才能得出数值。没有时会静默略过，仅用其余条目重新计算。即使不额外安装，状态栏分数、压缩保留模板等核心功能仍全部可用。
  • 若安装了同一作者的其他 mod agent-shell-watch，后台任务（等待中、执行中）也会计入分数。没有时该部分按“未知”处理，分数上限为 60 分（正常行为，并非必需安装）。
  • 交接判定只看代理最后一条回答中以指定前缀开头的行。无法检测提示词中“还有待办事项”这类自然语言叙述（README 中注明的限制）。
