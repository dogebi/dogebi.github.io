secret-redactor

secret-redactor · by claude-code-templates

在模型读到之前，清除工具结果里混入的 API 密钥、token、JWT、私钥和 DB 连接串。若想把被替换的占位符再用到命令里，则直接拦截

❯ /plugin marketplace add dogebi/k-mods
❯ /plugin install secret-redactor@k-mods
$ claude plugin marketplace add dogebi/k-mods
$ claude plugin install secret-redactor@k-mods

对已打开的会话，用 /reload-plugins 即可立即生效。需要 Claude Code 2.1.287 及以上。

注意事项

  • 与只遮蔽画面的 k-mods streamer-mode 不同，它会在模型收到之前把实际值删掉。但对象仅是工具结果，用户直接输入在提示中的敏感值无法遮蔽
  • tool.call 钩子没有 .catch(validate 警告，gatingHooks hasCatch:false)。出错时是 fail-open 还是 fail-closed 属于引擎内部行为，仅凭代码无法确定
  • 必须把它放在组织管理设置(managed settings)中最先执行的位置，才能在其他 plugin 看到原始值之前完成遮蔽(作者建议)
