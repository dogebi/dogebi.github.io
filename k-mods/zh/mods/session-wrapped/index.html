session-wrapped

session-wrapped · by OneWave AI

用 /wrapped 以动画形式显示本次会话的工具调用、测试和费用统计。分享用的 PNG 卡片会保存到桌面。

❯ /plugin marketplace add SeongGwangJu/k-mods
❯ /plugin install session-wrapped@k-mods
$ claude plugin marketplace add SeongGwangJu/k-mods
$ claude plugin install session-wrapped@k-mods

对已打开的会话，用 /reload-plugins 即可立即生效。需要 Claude Code 2.1.287 及以上。

注意事项

  • PNG 卡片 ~/Desktop中保存。
  • 会话结束时只会自动弹出 toast 通知，实际的回顾画面 /wrapped需要直接执行才会打开。
  • 统计值全部是用代码汇总工具调用次数、测试结果、token 用量得来的，生成摘要文案时不使用模型。

准备

  • python3
