modstage

modstage · by Varun Pratap Bhardwaj

把 Codex、Grok、Muse 等 7 种编码智能体作为 Claude Code 子智能体运行。在标签页里实时查看进度、审批危险操作，还能在运行中修改指令

❯ /plugin marketplace add dogebi/k-mods
❯ /plugin install modstage@k-mods
$ claude plugin marketplace add dogebi/k-mods
$ claude plugin install modstage@k-mods

对已打开的会话，用 /reload-plugins 即可立即生效。需要 Claude Code 2.1.287 及以上。

注意事项

  • 每次开始会话时都会启动本地桥接(Python 程序)。关闭 Claude Code 后桥接仍会继续运行，要停止请 kill $(cat ~/.modstage/bridge.pid)。
  • 12 个工具(stage_*,注册时不采用延迟加载。即使是不使用 ModStage 的会话，也会占用相当于工具说明的上下文。
  • 用 Bash codex exec, muse exec, grok -p 直接运行时会被拒绝，并 stage_start 并提示使用它。 --help, --version会照常执行。
  • 执行方式的默认值是 ask(危险操作需要请求批准)。auto 会自动允许代理的所有批准请求，而 Antigravity --dangerously-skip-permissions方式执行。即使在 ask 模式下，是否真的询问也取决于各 CLI 的设置。

准备

  • Python 3.10 及以上
  • 安装并登录至少 1 个代理 CLI(Codex、Grok、Muse、Antigravity、Kimi、Qwen Code、OpenCode 之一)
