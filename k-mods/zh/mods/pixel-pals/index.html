pixel-pals

pixel-pals · by hoobnn · plaxagoras

Claude 工作期间，喵猫、Clawd、闪电之类的像素伙伴会在输入框上方走过。这是精选 6 个场景并结合 clawd-tales 中 Clawd 故事的韩语版

❯ /plugin marketplace add dogebi/k-mods
❯ /plugin install pixel-pals@k-mods
$ claude plugin marketplace add dogebi/k-mods
$ claude plugin install pixel-pals@k-mods

对已打开的会话，用 /reload-plugins 即可立即生效。需要 Claude Code 2.1.287 及以上。

注意事项

  • 合并了两个原版:场景·宠物来自 hoobnn 的 spinner(hoobnn/hoobnn-agent-mods @ 8fb6f67)，tales 主题来自 plaxagoras 的 clawd-tales(@ 89c7f95)。两者都是 MIT，原始版权声明原样保留在 LICENSE·LICENSE-clawd-tales·NOTICE 中。
  • 从原版 spinner 的 15 种里只保留 nyan·clawd·thunder·chomp·sparky·bluecat 6 种，并把 clawd-tales 作为第 7 个主题 tales 加入。random 会在 7 种中每轮挑一个。读取系统声音的 audio 主题已被移除，因此不需要执行程序(swiftc)的权限。
  • 默认是韩语。/pals·/tales 的响应、终场画面以及 Clawd 故事的说明文字都以韩语显示(Clawd 故事只有韩语和英语)。
  • 命令有两个:/pals(主题·宠物·关闭)和 /tales(Clawd 故事的 demo·帽子·calm 模式)。tales 预览用 /tales demo。
  • nyan·chomp·sparky·bluecat 是原作者称为「像素致敬」的场景，Clawd 是 Anthropic 的吉祥物。这是非官方同人作品。
  • 只有在终端才能看到场景。在桌面应用中，只有使用 tales 主题时才会绘制横幅。
