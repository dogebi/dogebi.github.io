reels

reels · by Hamza Zafar

Claude 工作时在终端面板里播放 YouTube Shorts，任务结束后自动停止。只有输入 /reels 时才会播放。

❯ /plugin marketplace add dogebi/k-mods
❯ /plugin install reels@k-mods
$ claude plugin marketplace add dogebi/k-mods
$ claude plugin install reels@k-mods

对已打开的会话，用 /reload-plugins 即可立即生效。需要 Claude Code 2.1.287 及以上。

注意事项

  • 还直接阅读了代码(helper/reels.cjs)进行确认。用 Playwright 启动无头 Chrome 打开 https://www.youtube.com/shorts ，通过 CDP 屏幕广播捕获画面并保存为 PNG，然后显示在面板中。控制只通过本地 Unix 套接字(使用文件路径的 IPC)进行，不是对外开放的网络端口。
  • 配置(含 cookie 等)只保存在本地的 ~/.claude-mods/reels/profile。

准备

  • Playwright (首次执行 /reels 时会弹出安装提示: npm install --prefix <plugin> playwright)
