FAQ

What are Claude Code mods?

An official Claude Code feature since 2.1.287. JavaScript or TypeScript code inside a plugin receives events like tool calls and prompt submissions, and changes how Claude Code behaves or what it draws.

How do I install one?

Inside Claude Code, run /plugin marketplace add SeongGwangJu/k-mods once, then /plugin install name@k-mods. Run /reload-plugins to apply it to an open session.

Are they safe to install?

Mods run unsandboxed with your permissions. k-mods pins every external mod to the commit we reviewed and labels what each one can do, like network access, running programs or writing files.

Where does this list come from?

It is generated at build time from the registry folder of the SeongGwangJu/k-mods GitHub repository. Suggest a mod or fix its data with an issue or a pull request.
