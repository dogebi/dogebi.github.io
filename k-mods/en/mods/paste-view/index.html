paste-view

paste-view · by Clément Décou

See what you paste into Claude Code: image thumbnails and long-text previews above the prompt instead of bare placeholder tags.

❯ /plugin marketplace add SeongGwangJu/k-mods
❯ /plugin install paste-view@k-mods
$ claude plugin marketplace add SeongGwangJu/k-mods
$ claude plugin install paste-view@k-mods

Run /reload-plugins to apply it to an open session. Needs Claude Code 2.1.287 or later.
