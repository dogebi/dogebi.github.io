secret-vault

secret-vault · by Ray Amjad

Hides pasted or tool-read secrets, emails and IPs with stable placeholders, restoring real values only right before a tool runs.

❯ /plugin marketplace add SeongGwangJu/k-mods
❯ /plugin install secret-vault@k-mods
$ claude plugin marketplace add SeongGwangJu/k-mods
$ claude plugin install secret-vault@k-mods

Run /reload-plugins to apply it to an open session. Needs Claude Code 2.1.287 or later.

Notes

  • k-mods already has 'secret-redactor' (from davila7/claude-code-templates; it hides only tool results and blocks reuse). This mod (its original name was also secret-redactor, so it is registered as secret-vault to avoid the name collision) differs in that it also hides values you paste yourself, using the prompt.submit hook, and restores the hidden values to the originals right before a tool runs, so the workflow is not interrupted. The two mods overlap in some areas, so it would be good for marketing/operations to review whether to merge them.
  • The README says 'CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 is required' (this looks like wording from the early-access period), but on 2.1.291 validate passed right away with no extra setup.
