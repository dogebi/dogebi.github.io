todo-bar

todo-bar · by hoobnn

Shows the task list's progress in a band above the prompt, read from the todo and task tools' own calls: no tool, no prompt, no tokens.

❯ /plugin marketplace add SeongGwangJu/k-mods
❯ /plugin install todo-bar@k-mods
$ claude plugin marketplace add SeongGwangJu/k-mods
$ claude plugin install todo-bar@k-mods

Run /reload-plugins to apply it to an open session. Needs Claude Code 2.1.287 or later.

Notes

  • It draws only by reading the results of TodoWrite, TaskCreate and TaskUpdate after the fact. It registers no tool of its own and does not touch the prompt, so it uses no tokens.
  • Rejected or failed calls, and a subagent's own todo list, are not counted.
  • Per-session progress is kept locally for up to the 20 most recent sessions, so it carries on when you resume a session.
