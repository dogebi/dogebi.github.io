usage-band-pawandeep

usage-band-pawandeep · by Pawandeep

Always-visible 5-hour and weekly Claude usage percentages with a reset countdown above the prompt, plus new-chat and GitHub push buttons.

❯ /plugin marketplace add dogebi/k-mods
❯ /plugin install usage-band-pawandeep@k-mods
$ claude plugin marketplace add dogebi/k-mods
$ claude plugin install usage-band-pawandeep@k-mods

Run /reload-plugins to apply it to an open session. Needs Claude Code 2.1.287 or later.

Notes

  • The ↑ push button does not run git commands itself. It only submits to Claude a request to commit and then push, as if you had typed it yourself, so the actual git execution follows your normal permission settings.
  • The ＋ new chat button imitates a Ctrl+N/Cmd+N key press: with a bundled VBScript (wscript.exe) on Windows, and with osascript on macOS.
  • The next-steps plugin in the same repository is not part of this review (it uses the model call $.model.complete and needs a separate review).
  • Other usage display mods of a similar kind, mod-usage (Desktop/VS Code only, multilingual) and taxi-meter (taxi meter theme, conversion to Korean won), are also registered. This mod differs in that it works in both terminal and desktop and has new chat and GitHub push buttons.
