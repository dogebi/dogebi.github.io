pixel-player

pixel-player · by chrisluo5311

A pixel-art music player pane that streams your playlist through mpv, with a character that reacts to the music.

❯ /plugin marketplace add SeongGwangJu/k-mods
❯ /plugin install pixel-player@k-mods
$ claude plugin marketplace add SeongGwangJu/k-mods
$ claude plugin install pixel-player@k-mods

Run /reload-plugins to apply it to an open session. Needs Claude Code 2.1.287 or later.

Notes

  • Add YouTube links, direct audio URLs or local file paths to the playlist (~/.claude/pixel-play/playlist.txt), one per line. mpv connects directly to those addresses to play them; the mod itself does not connect anywhere else.
  • The playlist file is stored under ~/.claude/, not in the plugin folder, so it persists across updates.
  • Playback control (pause and resume) goes only through a local Unix socket (IPC) and uses no network.
  • The mpv launch arguments have no -- separator at the end, so a playlist line that starts with -- can be interpreted as an mpv option (for example, --script= loads an arbitrary Lua script). The playlist is a local file you write yourself, so the risk is low, but it is safer not to paste playlist lines from other people as they are.
  • Windows is not supported; it has only been tested on macOS.

Requires

  • mpv (required; without it only an install guide is shown and nothing plays)
  • yt-dlp (recommended for playing YouTube links)
