where-am-i

where-am-i · by Hamza Zafar

A live recap above the prompt (goal, doing now, waiting on you, next), with /where for a longer bullet-point summary.

❯ /plugin marketplace add SeongGwangJu/k-mods
❯ /plugin install where-am-i@k-mods
$ claude plugin marketplace add SeongGwangJu/k-mods
$ claude plugin install where-am-i@k-mods

Run /reload-plugins to apply it to an open session. Needs Claude Code 2.1.287 or later.

Notes

  • It is built to be aware of next-steps in the same repository. While next-steps' suggestion list is showing, this mod empties its own 'next' slot to avoid showing the same thing twice (it reads next-steps.active through $.state).
