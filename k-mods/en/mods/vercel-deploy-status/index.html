vercel-deploy-status

vercel-deploy-status · by Ray Amjad

Pins the linked Vercel project's deploy queue above the prompt, one line per deploy with phase and elapsed time.

❯ /plugin marketplace add SeongGwangJu/k-mods
❯ /plugin install vercel-deploy-status@k-mods
$ claude plugin marketplace add SeongGwangJu/k-mods
$ claude plugin install vercel-deploy-status@k-mods

Run /reload-plugins to apply it to an open session. Needs Claude Code 2.1.287 or later.

Notes

  • If the CLI or the link file is missing, it leaves one line in the debug log and quietly draws nothing.
  • The README says 'CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 is required' (this looks like wording from the early-access period), but on 2.1.291 validate passed right away with no extra setup.

Requires

  • vercel CLI (installed in PATH and logged in; check with vercel whoami)
  • A link file at .vercel/project.json in the repository (created by vercel link)
