diff-invaders

diff-invaders · by claude-code-templates

Space Invaders where every wave is made from the lines Claude's last Edit/Write actually added; zero tokens, played above the prompt.

❯ /plugin marketplace add SeongGwangJu/k-mods
❯ /plugin install diff-invaders@k-mods
$ claude plugin marketplace add SeongGwangJu/k-mods
$ claude plugin install diff-invaders@k-mods

Run /reload-plugins to apply it to an open session. Needs Claude Code 2.1.287 or later.

Notes

  • It can be played with only the arrow keys (←→/ad) and space, no mouse (clicking is also supported).
  • Only the high score is kept in $.store (plugin-only storage); nothing else is sent off the device.
  • The README states that 'nothing is drawn in claude -p, the desktop app or mobile' (terminal only).
