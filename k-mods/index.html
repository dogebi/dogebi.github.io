  • 나만의 mod 만들기mod를 만드는 방법은 두 가지예요. Claude에게 말로 시키거나, 직접 코드를 써도 돼요. 이 글은 두 방법을 모두 다루고, 마지막엔 완성한 mod를 k-mods에 올리는 절차로 이어져요.읽기

자주 묻는 질문

Claude Code mods가 뭔가요?

Claude Code 2.1.287부터 쓸 수 있는 공식 기능이에요. 플러그인 안의 자바스크립트·타입스크립트 코드가 도구 호출이나 프롬프트 제출 같은 이벤트를 받아 Claude Code의 동작을 바꾸거나 화면을 그려요.

어떻게 설치하나요?

Claude Code 안에서 /plugin marketplace add SeongGwangJu/k-mods를 한 번 입력하고, /plugin install 이름@k-mods로 원하는 mod를 설치해요. 열려 있는 세션에는 /reload-plugins로 바로 적용돼요.

설치해도 안전한가요?

mod는 샌드박스 없이 내 권한으로 실행돼요. 그래서 k-mods는 외부 mod를 검토한 커밋에 고정하고, 정적 분석으로 네트워크·프로그램 실행·파일 쓰기 같은 권한을 mod마다 표시해요.

목록은 어디서 오나요?

GitHub 저장소 SeongGwangJu/k-mods의 registry 폴더에서 빌드할 때 자동으로 만들어져요. mod를 제안하거나 정보를 고치려면 GitHub 이슈나 PR을 보내 주세요.
