modsチートシート（韓国語）

mods開発に必要なファイル構成、イベント、API、レンダーサイト、制限を表にまとめました。説明はできるだけ短くしたので、全体像は modsとは？ と 自分だけのmodを作るを先にご覧ください。

基準バージョンはClaude Code 2.1.291 です。バージョンごとにイベント・APIが変わりうるので、正確な定義は --plugin-dirでmodを読み込むときに生成される型宣言（.claude-plugin/types/claude-code/index.d.ts)がこのドキュメントより優先されます。

ファイル構成

ファイル 必須 内容
.claude-plugin/plugin.json はい プラグインのマニフェスト。modなので追加で必要なフィールドはありません
hooks/hooks.json はい modules ：フックモジュールのパス配列。 "modules": ["./register.js"] のように1つだけ書きます。設定フックも hooks キーの下に一緒に含められます
フックモジュール（例: hooks/register.ts) はい modのエントリポイント。 register(on, options) をエクスポートするESモジュール。拡張子： .js, .mjs, .cjs, .jsx, .ts, .mts, .cts, .tsx
types/index.d.ts (マニフェストの typesを指す） $.stateを使うとき、またはmods APIに名前空間を追加するときだけ PluginState 値と追加名前空間の宣言
*.test.ts / *.test.tsx いいえ claude plugin testが実行するテスト

register は on と options を受け取ります。 options は userConfig フィールドの値で、デフォルト値が入っています。

フック関数の引数

on(이벤트 이름, 매처?, 훅) として登録します。マッチャーはイベントフィールドを絞り込む任意のフィルタで、 on の戻り値は .catch(핸들러)を付けられるregistrationです。

引数 意味
$ mods API。必ず $.네임스페이스.메서드(...)まで省略せずに書きます
e イベントの入力値。深く凍結（frozen）されているので直接は変更できません。変更するにはコピーして nextに渡します
next(e) 次のハンドラ（他のmod、最後はClaude Code自体の動作）を呼びます。結果でresolveされます
next.signal イベントが中断されるとabortされる AbortSignal
next.origin このイベントを発行した側を含む { plugin, tier } 。Claude Code自身は { plugin: 'engine', tier: 'core' } で、modの tier は prepend/user/append/builtin
next.budget このフックのタイムアウト。 next.budget.ms は全体の上限、 next.budget.remainingMsは残り時間
next.to(e, tier) append/builtin/core のうち、さらに後ろのtierへスキップします。 prependPlugins·appendPluginsに属するmodのみ呼び出せます
next.error, next.called .catch ハンドラの中でのみ使います。 next.error.kind は throw や timeout, next.called は失敗したフックが nextを呼んだことがあるか

イベント

表の「返せるもの」から next(e) はそのまま通過、 next({ ...e, text }) はそのフィールドだけ変更して通過、オブジェクトをそのまま返すと nextを呼ばずに直接応答することです。

ツール

イベント いつ 返せるもの
tool.call ツールを実行する直前に next(e), { deny: 이유 }, { result }
tool.check tool.call と PreToolUse フックの後、実行するかどうかを決めるとき { decision } (allow/ask/deny)
tool.describe ツール説明をClaudeに初めて送るとき、ツールごとに1回 { description, isDeferred? }

プロンプトとClaudeが読むもの

イベント いつ 返せるもの
prompt.submit プロンプトが送信されるとき next({ ...e, text }), next({ ...e, context }), { drop: 이유 }
prompt.fill, prompt.suggest プロンプト入力欄に下書き・薄い提案が入る直前 変更後のテキストで next(e)
prompt.edit ユーザーがプロンプト入力欄を編集するとき next(e)
prompt.compose システムプロンプトを描画するとき { sections }
prompt.section システムプロンプトの名前付きセクションごとに1回 { text } 、省略するには { text: null }
prompt.context 会話ごとに1回、最初のメッセージと送信するコンテキスト { blocks }
prompt.attachment Claude Codeがリマインダーのようなメッセージを独自に追加するとき { text } 、省略するには { text: null }
skill.prompt スキル記事がClaudeに展開されるとき { text }
attribution.text コミット・PRの帰属文言を作るとき { text }

コマンドと設定

イベント いつ 返せるもの
command.run コマンドが実行される直前に { text }, {}, next(e)
command.describe コマンド一覧用の説明、コマンドごとに1回 { description, argumentHint, isHidden }
config.set /config 行の値が変わる直前 next({ ...e, value }), { deny: 이유 }
config.describe /config 行ごとに1回 { label, description, isHidden }

ターン

イベント いつ 返せるもの
turn.start ターンが始まるとき next(e)
turn.step モデルにリクエストを1つ送る直前（ツール呼び出しがあれば複数回） yield* next(e), next({ ...e, model }), next({ ...e, effort })
turn.complete ターンが終わったとき next(e) 、または回答の下に1行を表示する { text }

セッション

イベント いつ 返せるもの
session.start modごとに1回、最初のプロンプトの前（リロード後も実行、 /clear·/resume·/branch 以降は不可） next(e)
session.end セッション終了、または /clear·/resume·/branch next(e)
session.compact 会話を圧縮する直前に { skip: 이유 }
session.receive, session.send 他のエージェント・セッションとメッセージをやり取りするとき 受け取る { consumed: 이유 } 、送信 { isDelivered: false, reason }
session.append 会話に残る各行が保存される前 next({ ...e, message })
session.attach, session.detach 他のアプリがセッションに接続・切断するとき next(e)
session.measure ターンが終わるたび、プラン上限のパーセントが変わるとき next(e)

サブエージェント

イベント いつ 返せるもの
agent.offer サブエージェントの種類をClaudeに提案するとき 隠すには { isOffered: false }
agent.spawn サブエージェント・エージェントチームの同僚が起動する直前に モデル指定 next({ ...e, model }) 、拒否 { deny: 이유 }

インターフェース

イベント いつ
ui.render レンダーサイトを描画する直前に
ui.resolve modロード時、アプリ・サイト・modごとに1回
ui.press, ui.input, ui.select modが描画した Button/Input/Selectを使うとき
ui.focus, ui.scroll フォーカス・スクロール位置が変わる直前
ui.close パネルが閉じる直前
ui.message Client 要素がmodにデータを送るとき
ui.fault modが描画した Clientがロード・描画・実行に失敗したとき（2.1.289+）

他のmod

イベント いつ 返せるもの
plugin.register フックモジュールが読み込まれる直前。 e.usesにそのmodが受け取るイベント・呼び出し・環境変数・状態が含まれる { refuse: 이유 }
engine.create このmod用のmods APIを作るとき 名前空間を追加・削除したAPI

テレメトリ

イベント いつ 返せるもの
telemetry.log, telemetry.mark 使用量記録が残るか機能の使用が表示されるとき。インストールしたmodは { to: 'collector' } マッチャー必須 next(e), { deny: 이유 }

設定フックイベント: classic.<이벤트> という形です（例: classic.Stop, classic.PostToolUse). eは設定フックがstdinで受け取るJSONそのままです。

mods API呼び出し自体 ：すべてのmods APIメソッドは 네임스페이스.메서드 という名前のイベントでもあります（例: fs.read, model.complete, ui.open )。先行するmodが横取りして next(e), { deny: 이유 }, { value }で答えられます。

$ API名前空間

名前空間 メソッド 意味
$.plugin name, root このプラグインの名前とディレクトリ
$.ui resolve, invalidate, open, close, panes, focus, scroll, toast, status, log, notice, ask, copy, selection, blit 画面の描画、パネルの開閉、トースト・質問の表示
$.command register, run, list /명령어 追加・実行・一覧
$.tool register, call, check, list Claudeが使うツールの追加・呼び出し・検査・一覧
$.agent register, spawn, list サブエージェントの登録・実行・一覧
$.model complete, fork, classify 会話の外からモデルに直接質問
$.prompt submit, read, fill, suggest, compose プロンプトの送信・読み取り・入力欄の埋め込み
$.turn abort 進行中のターンを中断
$.session messages, cwd, root, model, turns, id, repo, surfaces, usage, version, compact, send, append, authorize セッション情報の読み取り、他のセッションへのメッセージ送信
$.config list, set /config 値の読み取り・書き込み
$.settings read 設定ファイル・管理ポリシーの読み取り
$.env get, set 環境変数の読み取り・書き込み
$.fs read, write, list, exists, stat, ancestors ファイルの読み取り・書き込み・一覧
$.store get, set, delete, keys このコンピューターのすべてのセッションが共有するキー・値ストア
$.state get, set (+ atom, read, update, derive, memberOf インポート） リアクティブな状態。値を書き込むと、その値を読む画面が自動で再描画されます
$.clock now, sleep, after, every タイマー（setTimeout·setInterval の代わりに）
$.http fetch ネットワークリクエスト
$.process run, spawn プログラム実行
$.mcp call, connect 接続されたMCPサーバーのツール呼び出し
$.audio play, speak 音を再生
$.telemetry log, mark 使用量記録（Claude Code・内蔵modが呼んだときだけ実際に送信される）

AssistantMessage 回答テキスト メッセージid ターミナル、デスクトップ

e.viewport には columns·rows·isFullscreen が入ります（測定前はなし）。パネル・帯の幅は e.props.bodyColumns で、dockステータスパネルの高さは e.props.scroll.bodyRowsに合わせます。

上限（limits）

項目 値
フック1つの実行時間（next・mods API呼び出しの待ち時間を除く） 10秒、 prompt.editは50ms
.catch ハンドラの実行時間 1秒
session.end フック全体 SessionEndフックの予算分（既定1.5秒）
$.process.run タイムアウト 既定30秒、最大10分
$.model.complete の maxTokens 既定1024、最大64,000またはモデル上限
$.fs.read/$.fs.write 1ファイルあたり4MiB
Text 子文字列1つ 10,000文字
$.store 全体で4MiBのJSON
$.session.messages() 最新4,096件の項目
$.ui.invalidate('ui.render') 再描画 1秒あたり10回（ターミナルの表示中のパネル・展開した帯・ヒント行は30回）に制限。それより速い呼び出しはまとめられる
$.ui.toast 既定4秒間表示
ユーザーの要求なしに開いたパネル ターミナルは144桁から表示、一度開いたことがあれば110桁から
コマンド・ツール・サブエージェント・パネル名 英字・数字・_·-、最大64文字
claude plugin test テスト1つ 既定5秒

設定・環境変数

名前 どこで 意味
CLAUDE_CODE_PLUGIN_DIRS 環境変数または ~/.claude/settings.json の env --plugin-dirのようにプラグインディレクトリを読み込む
CLAUDE_CODE_PLUGIN_DIR_WATCH 環境変数 1 なら非インタラクティブセッションも保存するとき --plugin-dir modをリロード
prependPlugins, appendPlugins managed settings（managed settingsがない個人ユーザーは自分で設定可能） modの実行順をユーザーmodより前・後ろに固定
allowManagedModsOnly managed settings（内蔵ガードオプション） 組織modと組み込みmodのみ読み込む
allowModsToOverrideDenyRules managed settings（内蔵ガードオプション） ユーザーmodが deny ルールを反転して承認させることを許可
allowManagedHooksOnly managed settings 組織のものでないフック・インストール済みmodをブロック
disableAllHooks すべての設定ファイル インストール済みmodのフックをすべて無効化（自分の設定なら自分のmodのみ、managed settingsならすべて）
disableSideloadFlags managed settings 開始時 --plugin-dir·--plugin-url 拒否
pluginConfigs ユーザーまたはmanaged settings mod の userConfig 値を保存

コマンド

コマンド やること
/plugin タブの下 N mods active · 이름のように読み込まれたmod数を表示
claude plugin validate <경로> マニフェストとフックモジュールを読み取り、エラー、受け取るイベント（hooks:)、呼び出すAPI(calls: )を出力。 --strict は警告もエラーとして、 --jsonは機械が読むレポートとして
claude plugin test [경로] .test.ts/.test.tsxで終わるファイルをすべて実行。失敗すると終了コード1
claude --plugin-dir <경로> 1つのセッションにだけプラグインディレクトリを読み込み、保存のたびにフックモジュールをリロード。何度でも繰り返し可能
/reload-plugins 実行中のセッションにプラグインの変更をすぐ反映
