ガイド

modsとは何かから、インストール、安全に使う方法、自分で作る方法まで整理しました。

ガイド一覧
  • modsとは？modはClaude Code 2.1.287から使える公式機能です。プラグイン（plugin）内のJavaScript・TypeScriptコードがツール呼び出しやプロンプト送信などのイベントを直接受け取り、Claude Codeの動作を変えたり画面を描画したりします。読む
  • インストールガイドk-modsは一般的なClaude Codeプラグインマーケットプレイスです。そのためインストール・アップデート・削除はすべてClaude Codeの/pluginコマンドとclaude pluginシェルコマンドで行います。読む

よくある質問

Claude Code modsとは？

Claude Code 2.1.287から使える公式機能です。プラグイン内のJavaScript・TypeScriptコードがツール呼び出しやプロンプト送信などのイベントを受け取り、Claude Codeの動作を変えたり画面を描画したりします。

インストール方法は？

Claude Code内で/plugin marketplace add dogebi/k-modsを一度入力し、/plugin install 名前@k-modsで目的のmodをインストールします。開いているセッションには/reload-pluginsですぐに反映されます。

インストールしても安全ですか？

modはサンドボックスなしで自分の権限で実行されます。そのためk-modsは外部modをレビュー済みのコミットに固定し、静的解析でネットワーク・プログラム実行・ファイル書き込みなどの権限をmodごとに表示します。

一覧はどこから来るのですか？

GitHubリポジトリdogebi/k-modsのregistryフォルダからビルド時に自動で生成されます。modの提案や情報の修正はGitHub IssueかPRでお送りください。
