image-view

image-view · by gggodlin

貼り付けた画像を[Image #1]のような文字の代わりに、入力欄の上のサムネイルとして表示します。

❯ /plugin marketplace add dogebi/k-mods
❯ /plugin install image-view@k-mods
$ claude plugin marketplace add dogebi/k-mods
$ claude plugin install image-view@k-mods

すでに開いているセッションには/reload-pluginsでそのまま適用されます。Claude Code 2.1.287以上が必要です。
