linear-board

linear-board · by linear-mod contributors

Linearのプロジェクト・マイルストーン・イシューをパネルに表示します。計画・実行・プロダクトのボタンからプロンプトをすぐに入力できます。

❯ /plugin marketplace add dogebi/k-mods
❯ /plugin install linear-board@k-mods
$ claude plugin marketplace add dogebi/k-mods
$ claude plugin install linear-board@k-mods

すでに開いているセッションには/reload-pluginsでそのまま適用されます。Claude Code 2.1.287以上が必要です。

必要なもの

  • Linear APIキー (lin_api_...)。/plugin configureまたはLINEAR_API_KEY環境変数

このmodが自分のコンピューターで行うこと

modはサンドボックスなしで自分の権限のまま実行されます。静的解析で確認した範囲です。

ネットワークプログラム実行プロンプト入力会話読み取り環境・設定の読み取り
