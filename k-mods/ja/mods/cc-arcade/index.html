cc-arcade

cc-arcade · by Seza Akgün

入力欄の上でスネーク・テトリス・2048・マインスイーパーなど9種類のミニゲームを楽しめます。Claudeが作業している間に育つペットも飼えます。

❯ /plugin marketplace add dogebi/k-mods
❯ /plugin install cc-arcade@k-mods
$ claude plugin marketplace add dogebi/k-mods
$ claude plugin install cc-arcade@k-mods

すでに開いているセッションには/reload-pluginsでそのまま適用されます。Claude Code 2.1.287以上が必要です。

注意点

  • ジャンルを模したクローンであり、Tetris Holding・Taito・Atari・id Softwareとは無関係です(アップストリームの説明のまま)。
  • ハイスコアとペットの状態はローカルの$.storeにのみ保存されます。
  • /arcade colorblindでDoomを赤・緑の区別がないパレットに変更できます。

必要なもの

  • 対話型ターミナル(非対話型 -p モードでは動作しません)
  • Claude Code 2.1.287未満の場合はCLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 の環境変数が必要

このmodが自分のコンピューターで行うこと

modはサンドボックスなしで自分の権限のまま実行されます。静的解析で確認した範囲です。
