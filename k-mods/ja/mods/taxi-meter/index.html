taxi-meter

taxi-meter · by 開発の弟 (devbrothers)

入力欄の上のタクシーメーターパネルにセッション料金と5時間・週間の上限を表示します。/meter・/receiptで詳しく確認できます。

❯ /plugin marketplace add dogebi/k-mods
❯ /plugin install taxi-meter@k-mods
$ claude plugin marketplace add dogebi/k-mods
$ claude plugin install taxi-meter@k-mods

すでに開いているセッションには/reload-pluginsでそのまま適用されます。Claude Code 2.1.287以上が必要です。

このmodが自分のコンピューターで行うこと

modはサンドボックスなしで自分の権限のまま実行されます。静的解析で確認した範囲です。
