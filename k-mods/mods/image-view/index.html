image-view

image-view · by gggodlin

붙여넣은 이미지를 [Image #1] 같은 글자 대신 입력창 위 썸네일로 보여줘요.

❯ /plugin marketplace add SeongGwangJu/k-mods
❯ /plugin install image-view@k-mods
$ claude plugin marketplace add SeongGwangJu/k-mods
$ claude plugin install image-view@k-mods

이미 열려 있는 세션에는 /reload-plugins로 바로 적용돼요. Claude Code 2.1.287 이상이 필요해요.

이 mod가 내 컴퓨터에서 하는 일

mod는 샌드박스 없이 내 권한으로 실행돼요. 정적 분석으로 확인한 범위예요.

프로그램 실행id, mv, sh대화 읽기환경·설정 읽기파일 읽기
정적 분석 결과

다루는 이벤트

prompt.submitsession.startui.render{component=AbovePrompt}ui.render{component=Pane, requestId=cc-image-view}ui.render{component=UserMessage}
