streamer-mode · by dogebi

화면을 공유·녹화할 때 토큰·이메일·전화번호·주민번호를 화면에서 가려요. Claude가 읽는 내용은 그대로예요

❯ /plugin marketplace add dogebi/k-mods
❯ /plugin install streamer-mode@k-mods
$ claude plugin marketplace add dogebi/k-mods
$ claude plugin install streamer-mode@k-mods

이미 열려 있는 세션에는 /reload-plugins로 바로 적용돼요. Claude Code 2.1.287 이상이 필요해요.
